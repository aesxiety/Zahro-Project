# Static Assets Directory

Place your static assets here to serve them directly from the root URL.

## Folder Structure

- `/public/documents/` - Put your PDFs, catalogs, and other document files here.
  - Example: A file at `/public/catalog.pdf` can be accessed in your code as `/catalog.pdf` or downloaded via `<a href="/catalog.pdf" download>`.
- `/public/images/` - Put your images, icons, logos, and banners here.
  - Example: A file at `/public/images/logo.png` can be referenced in your code as `/images/logo.png`.
